# AIQuartSmart Community Edition 社群版使用指南

本指南介紹社群版的自託管與量化研究流程。社群版使用部署者自行設定的資料來源，不連線專案生產閘道；不提供官方 AI 洞察、智能研究、AI 分析師或官方 AI 風險評估。

> 本系統僅供研究與模擬交易，不構成投資建議、收益承諾或真實交易指令。使用第三方資料與模型前，請確認其授權和使用限制。

## 1. 登入與初始化

啟動後端與前端，開啟前端網址並註冊帳號。首次使用由管理員完成資料庫初始化、密碼修改、站點設定及權限確認。管理員可分別開關演示模式、新手引導與各項資料 Provider。

## 2. 設定資料來源

在後端 `.env` 設定資料庫與 Provider，可先使用 Mock，再改用 CSV 或自行撰寫 Provider。請勿把 API Key、Cookie 或授權資料寫入前端原始碼。啟用 Provider 前，核對條款、限流、署名、快取及資料保存要求。

## 3. 匯入 CSV 證券池

將使用者維護的 CSV 放在任意本地路徑，透過 `import_security_universe.py --file` 匯入。社群版不附帶行情抓取或定時更新腳本。

```csv
code,name,industry,area,board,asset_type
600519,貴州茅台,白酒,中國,主板,stock
hk00700,騰訊控股,網際網路服務,香港,港股,stock
usAAPL,Apple,Technology,United States,NASDAQ,stock
510300,滬深300ETF,指數基金,中國,ETF,etf
```

使用 `python import_security_universe.py --file ./path/to/your-universe.csv` 匯入本地證券池。社群版不附帶行情抓取或定時更新腳本。

## 4. 選股與因子

在行情與選股器搜尋代碼、建立觀察清單並組合條件。因子頁面支援內建因子、表達式驗證、預覽與自訂因子；結果保存在你的部署資料庫中。

## 5. 策略、回測與模擬交易

在策略工作台編寫規則，選擇證券池、日期、初始資金與基準執行回測。檢查收益、回撤、波動率、換手及交易明細，再綁定到模擬帳戶；模擬交易不會連線真實券商。

佣金為 `max(成交金額 × 費率, 最低佣金)`。費率採萬分比，填 `1` 代表萬 1（0.01%）；預設最低佣金 5 元。管理員可按市場調整，最低佣金設為 0 即按實際費率計算。

## 6. 自訂風險規則與 AI（可選）

風險頁面只顯示資料來源指標及使用者設定規則。社群版不提供官方風險評分或動態權重，請自行定義閾值、通知與處置流程。需要 AI 時，在自己的環境接入 API、Agent 或 Workflow，並自行負責模型、費用與資料合規。

## 7. 演示模式與新手引導

兩者獨立且預設開啟。管理員可指定測試帳號並分別開關。演示帳號的相同請求會優先使用瀏覽器快取；新手引導以步驟動畫呈現，可跳過、返回、完成或點選步驟切換。

## 8. 安全與疑難排解

資料為空時檢查 Provider 憑證、交易日、代碼格式與限流狀態；離線可切換 Mock 或 CSV。不要提交金鑰、Cookie、受限資料檔、生產網址或使用者資料，並限制管理端公開存取。
