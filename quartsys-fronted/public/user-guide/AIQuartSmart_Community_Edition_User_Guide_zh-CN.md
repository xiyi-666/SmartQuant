# AIQuartSmart Community Edition 社区版使用指南

本文介绍社区版的本地部署和量化研究流程。社区版默认使用部署者自行配置的数据源，不连接项目生产网关；平台不提供官方 AI 洞察、智能研究、AI 分析师或官方 AI 风险评估。

> 本系统用于研究和模拟交易，不构成投资建议、收益承诺或真实交易指令。请在使用第三方数据和模型前确认其授权与使用限制。

## 1. 登录与初始化

启动后端和前端，打开前端地址并注册账号。首次使用请由管理员完成数据库初始化、密码修改、站点设置和权限确认。管理员可在后台分别开启或关闭演示模式、新手引导和各项数据 Provider。

## 2. 配置数据源

在后端 `.env` 中设置数据库和本地 Provider。可从 Mock 开始，也可使用 CSV 或自行编写 Provider。社区版请求路径为：

```text
你的部署环境 → 你配置的数据源 → 第三方服务 → 本地 API 与界面
```

不要把 API Key、Cookie 或授权数据写入前端源码。启用 Provider 前，请核对条款、限流、署名、缓存和数据保存要求。

## 3. 导入 CSV 证券池

将用户维护的 CSV 放在任意本地路径，通过 `import_security_universe.py --file` 导入。社区版不附带行情抓取或定时更新脚本。

```csv
code,name,industry,area,board,asset_type
600519,贵州茅台,白酒,中国,主板,stock
hk00700,腾讯控股,互联网服务,香港,港股,stock
usAAPL,Apple,Technology,United States,NASDAQ,stock
510300,沪深300ETF,指数基金,中国,ETF,etf
```

运行 `python import_security_universe.py --file ./path/to/your-universe.csv` 导入本地证券池。社区版不附带行情抓取或定时更新脚本。

## 4. 选股与因子

在“行情”和“选股器”中搜索代码、建立观察列表并组合筛选条件。因子页面支持内置因子、表达式校验、预览和自定义因子。研究结果保存在你的部署数据库中，可按交易日复查。

## 5. 策略、回测与模拟交易

在策略工作台编写或导入规则，选择证券池、日期、初始资金和基准后运行回测。检查收益、回撤、波动率、换手和交易明细，再把策略绑定到模拟账户。模拟交易不会连接真实券商。

佣金公式为 `max(成交金额 × 费率, 最低佣金)`。费率使用万分比，填 `1` 代表万 1（0.01%）；默认最低佣金为 5 元。管理员可以按市场调整，最低佣金设为 0 即按实际费率计算。

## 6. 自定义风险规则与 AI（可选）

风险页面只展示数据源提供的指标以及管理员或用户配置的规则。社区版不提供官方风险评分和动态权重，请自行定义阈值、通知和处置流程。

如需 AI，可在自己的环境配置 API、Agent 或 Workflow。模型调用、费用、日志、提示词和数据合规由部署者负责，社区版不会自动调用平台模型。

## 7. 演示模式与新手引导

演示模式和新手引导是两个独立功能，默认都开启。管理员可以指定测试账号并分别开关。演示账号的相同请求会优先使用浏览器缓存，减少重复调用 AI；新手引导使用步骤动画，可跳过、返回、完成或点击步骤点切换。

## 8. 常见问题

**数据为空：** 检查 Provider 凭据、交易日、代码格式和限流状态；离线时可切换 Mock 或 CSV。

**港美股字段不完整：** 不同市场的披露和数据覆盖不同，请以数据源原始结果为准。

**页面没有官方 AI 功能：** 这是社区版的预期边界；请接入自己的 AI 工作流。

## 9. 安全检查

不要提交密钥、Cookie、受限数据文件、生产网址或用户数据。定期备份本地数据库，并在公开部署前限制管理端访问。
