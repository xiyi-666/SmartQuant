## ADDED Requirements

### Requirement: 前端 API 基址必须由显式配置驱动
系统 SHALL 以环境变量或运行时显式配置作为前端 API 基址的主来源，不得在默认运行路径中依赖多个本地地址自动探测来决定联接目标。

#### Scenario: 已提供显式 API 基址
- **WHEN** 环境变量或运行时配置提供了 API 基址
- **THEN** 系统仅使用该地址发起请求，并将其视为当前联接目标

#### Scenario: 缺少 API 基址配置
- **WHEN** 运行环境未提供 API 基址配置
- **THEN** 系统返回明确的配置错误或受控开发态兜底行为，不得静默尝试多个硬编码生产/本地地址

### Requirement: 示例配置不得包含可直接使用的敏感默认值
系统 SHALL 将 `.env.example`、README 和相关示例配置中的密钥、模型和后端地址改为安全占位值，不得保留可直接调用的真实凭证或误导性默认地址。

#### Scenario: 查看示例环境文件
- **WHEN** 开发者打开 `.env.example`
- **THEN** 文件仅包含占位示例值和使用说明，不包含可直接使用的真实 API key 或生产地址

#### Scenario: 查看接入文档
- **WHEN** 开发者按照 README 或集成文档进行启动
- **THEN** 文档说明的默认联接方式与当前代码主路径保持一致，不要求依赖隐式本地端口试探

### Requirement: 后端敏感运行配置必须脱离源码硬编码
系统 SHALL 将 JWT 密钥和同类敏感运行配置迁移到环境变量或部署配置中，不得继续在源码中使用固定默认密钥作为正常运行值。

#### Scenario: 启动后端服务
- **WHEN** 服务在正常环境中启动
- **THEN** JWT 和同类敏感配置从环境或部署配置加载，而不是使用固定源码常量

#### Scenario: 缺少必要敏感配置
- **WHEN** 部署环境缺少必要敏感配置
- **THEN** 系统给出明确启动错误或降级告警，避免以不安全默认值继续运行
